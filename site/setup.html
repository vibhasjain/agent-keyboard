Agent Keyboard

Run Agent Keyboard on your own accounts

Claude Code sets it up with you, on your own computer: the server goes into your Fly account and runs on your own Claude subscription. Your keys never pass through us, and you never paste one into the chat.

1. What you need

  • A Claude Pro or Max plan, and Claude Code installed.
  • Free accounts on GitHub, Fly.io and Supabase. Fly bills you directly, about $2–6 a month.
  • A website, or nothing yet: Claude can start one from an empty repo, host it and point your domain at it.

2. Run this in your terminal

gh repo fork vibhasjain/agent-keyboard --clone && cd agent-keyboard && claude "set up Agent Keyboard"

No gh? Install it from cli.github.com, or fork the repo on GitHub and clone it.

3. What Claude does with you

  1. Asks about your site, or creates one: repo, hosting, and the DNS record for your domain.
  2. Signs you in to GitHub, Fly and the rest through your browser. For the few keys the server needs, it gives you a one-line command for a separate terminal window, so you paste each key where it stays hidden.
  3. Sets up Supabase sign-in, deploys the server to Fly and checks every piece works.
  4. Adds the script tag to your site. You sign in to the bar and ask for your first change.
